# Inventory CSA Lab

A small Python project used to practise software maintenance and
Configuration Status Accounting (CSA) with Git.

## Project Structure
- `inventory.py` – inventory data (items with name, quantity and price)
- `app.py` – main script; prints the report and total stock value
- `utils/helpers.py` – helper functions (highest and lowest stock item)
- `requirements.txt` – dependencies

## Usage
1. Install Python 3.
2. Run: `python app.py`
